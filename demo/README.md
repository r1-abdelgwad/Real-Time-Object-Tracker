# Demo Video

Place your recorded 30–60 second demonstration video here as `demo.mp4`.

## Recording Checklist for Demo:
1. **Launch**: Run `python src/tracker.py`
2. **Webcam**: Ensure webcam feed is clear
3. **ROI Selection**: Press `R`, draw bounding box around object, press `ENTER`
4. **Normal Motion**: Move object horizontally and vertically (`Tracking: ON` in Green)
5. **Rotation**: Rotate object ($45^\circ$, $90^\circ$, $180^\circ$)
6. **Occlusion / Recovery**: Cover object briefly with hand (`Tracking: RECOVERING` in Amber), then uncover to show automatic recovery
7. **Clean Exit**: Press `Q` or `ESC`
